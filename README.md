# AI-Driven Digital Human Newscaster

An AI-powered digital human system designed to modernize news delivery using realistic 3D avatars, speech synthesis, and conversational AI.  
The system supports interactive communication through multiple chatbot modes and lifelike digital human animation.

---

# Project Overview

This project introduces an AI-based digital newscaster that delivers news and conducts interviews using realistic 3D avatars.

**Key Idea**
- Replace traditional static news delivery
- Improve engagement using conversational AI
- Provide customizable avatar-based interaction
- Support real-time communication with users

The system combines:
- Artificial Intelligence  
- Speech Processing  
- 3D Digital Humans  
- Conversational Chatbots  

---

# Features

- 3D human-like avatar with natural movements  
- Text-to-speech based news delivery  
- Speech recognition for user interaction  
- Multiple chatbot modes  
- Real-time conversational interviews  
- Avatar gender selection  
- Multiple dialect support  
- Interactive user experience  

---

# Chatbot Modes

## Repeater Mode
- Reads and delivers news scripts  
- Accepts text or voice input  
- Acts as a virtual news anchor  

## Interview Mode
- Conducts real-time conversations  
- Asks dynamic questions  
- Simulates live news interviews  

---

# Technology Stack

- Python  
- SpeechRecognition  
- pyttsx3 (Text-to-Speech)  
- Hugging Face API  
- Unreal Engine  
- MetaHuman SDK  
- ConvAI  
- 3D Avatar Rendering  

---

# System Workflow

1. User provides input (text or voice)  
2. Speech input is converted to text  
3. AI processes the input  
4. Response text is generated  
5. Text is converted to speech  
6. Avatar delivers the output visually
